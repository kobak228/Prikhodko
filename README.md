# Система учёта событий устройств  
## Краткое описание проекта  
Проект представляет собой базу данных для хранения информации об устройствах и событий, которые с ними происходят. Система позволяет хранить список устройств, их местоположение, время событий, тип события и числовые показания, например температуру.  
## Назначение системы  
База данных предназначена для учёта и анализа работы устройств. С её помощью можно узнать историю событий конкретного устройства, подсчитать количество событий разных типов и определить устройства, у которых возникают ошибки.  
## Структура таблиц  
```
devices
```
Таблица содержит информацию об устройствах:  
* device_id — уникальный идентификатор устройства, первичный ключ;  
* name — название устройства;  
* location — место расположения устройства.  
```
events
```
Таблица содержит информацию о событиях устройств:  
* event_id — уникальный идентификатор события, первичный ключ;  
* device_id — идентификатор устройства, внешний ключ, связанный с devices.device_id;  
* event_time — дата и время события;  
* event_type — тип события: включение, выключение, показание или ошибка;  
* value — числовое значение для событий типа показание. Для остальных типов событий значение отсутствует (NULL).  
Связь между таблицами: одному устройству из devices может соответствовать множество событий в events.  
## Разворачивание базы данных с нуля  
1. Создать новую базу данных SQLite.  
2. Выполнить SQL-скрипт создания таблиц.  
3. Добавить в таблицу devices информацию об устройствах.  
4. Добавить в таблицу events события, связанные с соответствующими устройствами через device_id.  
5. После заполнения базы можно выполнять запросы для анализа событий и состояния устройств.  
Для повторного разворачивания базы с нуля необходимо удалить существующий файл базы данных и заново выполнить SQL-скрипт.  
## Результат диагностики  
Чаще всего ошибки сообщает гигрометр — у него зафиксировано две ошибки. У термостата зафиксирована одна ошибка, а у барометра ошибок нет, поэтому гигрометр стоит проверить в первую очередь.
